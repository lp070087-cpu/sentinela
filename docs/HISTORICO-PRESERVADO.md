# Histórico de origem preservado

A apresentação original foi recuperada de seu repositório de origem com o commit `48daa7ac6e76b2a951ea1a6058d25ed5ef8efd69`.

O histórico exato está incluído em `docs/apresentacao-original.bundle`. Verificação: `git bundle verify docs/apresentacao-original.bundle`. Para importar a referência em um clone local, use `git fetch docs/apresentacao-original.bundle refs/heads/history/apresentacao-original:refs/heads/history/apresentacao-original`.

O repositório GitHub autorizado estava vazio no início desta publicação. Como o Git do terminal não possui credencial de escrita, a publicação usa a integração GitHub autenticada com atualização sem force e verificação do commit remoto. Isso não reescreve um histórico remoto existente. O bundle preserva a identidade e a ancestralidade exatas da origem, enquanto a branch main do GitHub mantém seu próprio histórico de publicação.

Nenhuma alteração foi enviada de volta ao repositório de hospedagem original e nenhum deploy Vercel foi iniciado nesta fase.
